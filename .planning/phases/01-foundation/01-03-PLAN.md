Create `SettingsActionsComponent` as a standalone Angular component. This component renders at the bottom of the Settings page (below the tab group in `SettingsComponent`). Add it to `SettingsComponent`'s template and imports.

**Template layout:**
A section with a separator/divider at the top, then a row of three actions:
- "Export Settings" button (`mat-stroked-button`, icon `download`)
- "Import Settings" button (`mat-stroked-button`, icon `upload`)
- "Factory Reset" button (`mat-stroked-button color="warn"`, icon `delete_forever`)
Label under each button (small text) explaining what it does.

**Export Settings (`onExport()`):**
1. Call `PolicyEngineIpcService.exportSettings()` — returns `PeNonSecretSettings`.
2. Create a JSON blob: `new Blob([JSON.stringify(data, null, 2)], { type: 'application/json' })`.
3. Create a temporary `<a>` element, set `href = URL.createObjectURL(blob)`, `download = 'policy-engine-settings.json'`, click it, then revoke the object URL.
4. Show snackbar "Settings exported (secrets excluded)".

**Import Settings (`onImport()`):**
1. Create a hidden `<input type="file" accept=".json">` element (can be in template with `#fileInput`).
2. Trigger its click to open OS file picker.
3. On `change` event: read the file as text, parse JSON, call `PolicyEngineIpcService.importSettings(parsedData)`.
4. If success: show snackbar "Settings imported. Re-enter secrets to apply." No redirect.
5. If error: show snackbar "Import failed: [error message]" with longer duration (5s).
6. Reset the file input after import so the same file can be re-imported if needed.

**Factory Reset (`onFactoryReset()`):**
Two-step confirmation using `MatDialog`. Since plan 02 may not have a pre-built confirm dialog, implement inline using MatDialog with a `templateRef` or a minimal inline component.

Step 1 — First click: open `MatDialog` with message:
> "This will delete ALL Policy Engine settings and stored secrets. This cannot be undone."
> Buttons: [Cancel] [Delete Everything]

Step 2 — "Delete Everything" click: call `PolicyEngineIpcService.factoryReset()`. On success:
- Show snackbar "All settings cleared" (3s).
- Navigate to `/policy-engine/settings` (Router.navigate — this naturally re-opens settings fresh, re-triggering init which will show empty forms and setup banner).

For the MatDialog confirm: create a simple inline template-based approach using `MatDialogModule`:
```typescript
// In onFactoryReset(): open a dialog with data
const dialogRef = this.dialog.open(ConfirmResetDialogComponent, {
  data: { message: 'This will delete ALL Policy Engine settings and stored secrets. This cannot be undone.' },
  width: '420px'
});
dialogRef.afterClosed().subscribe(confirmed => {
  if (confirmed) { /* call factoryReset */ }
});
```
Create `ConfirmResetDialogComponent` as a private inline component in the same file (Angular allows this for small dialogs). Use `MatDialogModule`, `MatButtonModule` in its imports. Template:
```html
<h2 mat-dialog-title>Factory Reset</h2>
<mat-dialog-content>{{ data.message }}</mat-dialog-content>
<mat-dialog-actions align="end">
  <button mat-button mat-dialog-close>Cancel</button>
  <button mat-button color="warn" [mat-dialog-close]="true">Delete Everything</button>
</mat-dialog-actions>
```
Inject `data` via `inject(MAT_DIALOG_DATA)`.
