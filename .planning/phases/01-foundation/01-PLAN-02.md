import { CanDeactivateFn, ActivatedRouteSnapshot, RouterStateSnapshot } from '@angular/router';
import { inject } from '@angular/core';
import { MatDialog } from '@angular/material/dialog';
import { map } from 'rxjs/operators';

export interface HasUnsavedChanges {
  hasUnsavedChanges(): boolean;

**Step C — Create IscConnectionTabComponent (standalone):**
Imports: `ReactiveFormsModule`, `MatFormFieldModule`, `MatInputModule`, `MatButtonModule`, `MatSnackBarModule`, `MatIconModule`, `MatTooltipModule`, `MatProgressSpinnerModule`, `CommonModule`.
FormGroup fields:
- `tenantUrl`: `['', [Validators.required, Validators.pattern(/^https:\/\/[a-zA-Z0-9-]+\.api\.identitynow\.com\/?$/)]]`
- `patClientId`: `['', Validators.required]`
- `patSecret`: `['']` — not required in the form (validation: required only if no secret is currently stored — handle via `onSaveAttempt()` check separately)

On component init (`ngOnInit`):
1. Call `PolicyEngineIpcService.getSettings()`.
2. Patch `tenantUrl` and `patClientId` from result.
3. If `result.patSecretStored === true`, set `patSecretField` placeholder to `••••••••••` and store `patSecretAlreadyStored = true` on component.
4. If `result.patSecretStored === false`, `patSecretAlreadyStored = false`.
5. Call `form.markAsPristine()` after patching so the form does not start dirty.

Secret field behavior:
- `type="password"` on the patSecret input — no show/hide toggle (always masked per locked decision).
- `placeholder="••••••••••"` when `patSecretAlreadyStored === true`; `placeholder="Enter PAT secret"` when false.
- Value is NEVER pre-populated from the stored secret.
- Lock icon (`mat-icon`) + `matTooltip="Encrypted via OS keychain (safeStorage)"` next to the field.
- "Remove stored secret" button: small text button with mat-icon `lock_open`. On click: call `PolicyEngineIpcService.clearSecret('patSecret')`, then set `patSecretAlreadyStored = false`, clear the form field, show snackbar "Secret removed".

Save logic (`onSave()`):
1. Mark all fields as touched to trigger validation display.
2. Validate: if `tenantUrl` or `patClientId` invalid, return early.
3. Validate: if `!patSecretAlreadyStored && !form.value.patSecret`, show inline error "PAT secret is required". Return early.
4. Build payload: `nonSecrets.isc = { tenantUrl, patClientId }` merged with current full settings (call `getSettings` to get full settings and merge — or cache the full settings on init).
5. Only include `patSecret` in payload if `form.value.patSecret` is a non-empty string.
6. Call `PolicyEngineIpcService.saveSettings(payload)`.
7. On success: `form.markAsPristine()`, show `MatSnackBar.open('Settings saved', '', { duration: 2500 })`, set `patSecretAlreadyStored = true` if a new secret was sent.
8. If this was the first ISC save (previously `tenantUrl` was empty), emit an event or set a local flag to trigger the "run Test Connection" prompt on PE home.

Dirty tracking:
- `get isDirty(): boolean { return this.form.dirty; }` — used by SettingsComponent for tab dot + hasUnsavedChanges.
- Tab label dot: managed by SettingsComponent using `@ViewChild` + `isDirty` getter.

Validation display:
- All validation errors: inline via `<mat-error>` inside `<mat-form-field>` using `@if (field.errors?.['required'])` etc.
- Trigger: on blur (`updateOn: 'blur'` for individual controls) AND on save attempt (mark all as touched).
