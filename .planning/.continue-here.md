<decisions_made>

## Core Design
- lifecycleType: "complex" ONLY in v1 (user provides transform refs returning "true"/"false") — simple/medium deferred
- Affiliations: pipe-delimited string (e.g., "staff|faculty")
- 4 identity attributes: affiliations, primaryAffiliation, cloudLifecycleState, {policyName}LifecycleState
- 1 identity profile, all transforms wired to it
- Per-policy configurable owner, resolved by ISC identity search (name → UUID)
- Newest HR account wins when multiple accounts exist for same identity
- Null endDate → firstValid fallback to "12/31/2099"

## Deployment
- Explicit Deploy button (local-first, no auto-push)
- Dependency order: transforms → identity profile → entitlement ID resolution → access profiles → roles → segments → segment-role assignment → provisioning policies
- Rollback on failure, drift detection before deploy, pre-deploy diff viewer
- "Apply Changes" triggers ISC identity refresh with confirmation popup

## Audit / Git
- Git committer = configured service account (not logged-in user)
- Operator identity = resolved from ISC token response identity_id → GET /v2025/identities/{id}
- Operator name embedded in commit messages
- Batched git push every N minutes (default 5), skip if nothing to push
- Local audit log in Electron store: who/what/when/before/after/API responses

## API Constraints (Critical — affect implementation)
- Transform name+type immutable after creation (only attributes updatable via PUT)
- Transform deletion blocked if referenced in identity profile
- identityAttributeConfig only allows accountAttribute, reference, rule types
- Entitlements referenced by UUID (not DN) — must resolve before creating access profiles
- Roles list API: max 50 per page
- Segment visibilityCriteria: only AND + EQUALS, max 1 level deep
- Provisioning policy OU: must use identityAttribute (not accountAttribute) in field transforms
- OAuth token endpoint: /oauth/token (not under /v2025/)
- No /me endpoint — use identity_id from token response

## v1 Scope Cuts (Deferred to Future)
- lifecycleType simple/medium
- Entitlement browser (pick from ISC UI)
- Dev → Prod promotion (export/import)
- Policy impact simulation

</decisions_made>
